Open into the work.

Three workspace-first shells remove the Home screen and keep a real Workspace, a table-shaped editor, and an independent AI Agent visible from the first frame.

Recommended direction

Workspace Loom

Use Kition's immediate three-region clarity, Teable's explicit scope model, and Cursor's ordered work evidence—then express them through IdeaNote's local-file and editor ownership. Atlas Table and Agent Ledger remain useful specialist references.
