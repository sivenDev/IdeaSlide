# GFM Editing Reference

Apply these rules when editing GitHub Flavored Markdown source:

- Keep ATX heading depth and surrounding section order stable unless restructuring is requested.
- Preserve reference-style links and footnote-like definitions verbatim when they are outside the requested range.
- Maintain list marker style, nesting indentation, task-list markers, and ordered-list numbering policy.
- Keep fenced code language tags and use a fence long enough to contain any backticks in the body.
- Preserve table delimiter rows and column count; do not pad columns merely for appearance.
- Treat inline HTML as source text. The preview does not execute raw HTML.
- Use relative document links as written; do not resolve or fetch them through Agent Tools.
- Prefer the smallest exact range that completes the request, and re-read when earlier edits or user actions may have changed it.
